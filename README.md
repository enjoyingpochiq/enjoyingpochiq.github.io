# 🛡️ Offensive Security Portfolio

Bienvenido al repositorio de mi portfolio personal. Este proyecto ha sido diseñado y desarrollado desde cero para reflejar mi perfil como **Junior Pentester & Red Teamer**, priorizando el rendimiento, la escalabilidad y un diseño UI/UX premium (estilo Dark/AuthKit).

🌐 **[Ver Portfolio en Vivo](https://tu-dominio-o-enlace-de-vercel.com)**

---

## ✨ Características Principales

Más allá de ser una simple web estática, este portfolio funciona como un motor de contenido dinámico para documentar mi aprendizaje continuo:

- **🎨 Diseño Premium "Red Team":** UI oscura basada en la escala Zinc de Tailwind, con acentos en rojo carmesí, efectos de *glow* (resplandor) y un diseño Bento Grid interactivo.
- **📝 Motor de Markdown (Astro Content Collections):** Sistema automatizado para publicar Writeups de CTFs y entradas de Micro-blog. Solo necesito escribir archivos `.md` y el sistema genera las páginas, valida los metadatos (Frontmatter) y aplica el estilo de lectura.
- **📊 Roadmap Interactivo:** Tracker de certificaciones integrado (ej. CPTS) con barra de progreso dinámica y menú colapsable sin dependencias pesadas de JavaScript.
- **⚡ Rendimiento Extremo:** Construido con **Astro**, enviando cero JavaScript innecesario al cliente (arquitectura *Islands*), logrando puntuaciones perfectas en Lighthouse.
- **🎬 Animaciones Nativas:** Integración de AOS (Animate On Scroll) y transiciones fluidas de Tailwind para una experiencia de usuario envolvente.

## 🛠️ Stack Tecnológico

- **Framework:** [Astro v6](https://astro.build/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/) + Typography Plugin
- **Animaciones:** AOS (Animate On Scroll)
- **Despliegue:** [Vercel / GitHub Pages]
- **Lenguajes:** TypeScript, HTML, CSS, JavaScript nativo.

## 🚀 Instalación y Uso Local

Si quieres clonar este proyecto o ejecutarlo en tu máquina local:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/tu-usuario/tu-repo.git](https://github.com/tu-usuario/tu-repo.git)
   cd tu-repo
   ```

2. **Instalar dependencias:**
    ```bash
    npm install
    ```

3. **Arrancar el servidor de desarrollo:**
    ```bash
    npm run dev
    ```
